# 审计日志记录 (AuditLogging)

## 核心用户故事

作为系统安全审计人员，我希望系统自动记录关键操作的审计日志，以便事后追溯和分析安全事件。

## 功能名称和一句话概括

审计日志记录 — 记录登录事件和管理操作的审计日志。

## 补充约束

- 审计日志写入失败仅记录日志，不抛异常
- 登录历史保留 90 天，审计日志保留 365 天
- 审计日志包含 before/after 快照（JSON 格式）

## 关键验收条件摘要

1. [ ] 登录成功/失败记录到 login_histories
2. [ ] 管理操作记录到 audit_logs（含快照）
3. [ ] 审计日志可通过 Admin API 查询

## 明确列出"范围外"

- 不提供审计日志的导出功能
- 不提供实时告警
