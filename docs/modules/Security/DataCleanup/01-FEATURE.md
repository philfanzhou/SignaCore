# 过期数据自动清理 (DataCleanup)

## 核心用户故事

作为系统运维人员，我希望系统自动清理过期数据（令牌、验证码、登录尝试、历史记录等），以便数据库不会无限增长。

## 功能名称和一句话概括

过期数据自动清理 — 后台服务定期清理各类过期数据并检查密钥轮换。

## 补充约束

- 清理间隔默认 24 小时
- 各类数据有独立的保留期策略
- 清理失败仅记录日志，不影响服务运行

## 关键验收条件摘要

1. [ ] 清理过期/已撤销的刷新令牌
2. [ ] 将过期应用注册标记为不活跃
3. [ ] 清理过期非活跃的密钥记录
4. [ ] 清理过期的登录尝试记录
5. [ ] 清理超过保留期的登录历史（90 天）
6. [ ] 清理超过保留期的审计日志（365 天）
7. [ ] 检查并执行密钥轮换

## 明确列出"范围外"

- 不清理活跃数据
- 不提供手动清理接口
