# 网关用户查询 (UserQuery)

## 核心用户故事

作为业务系统的后端服务，我希望通过网关 API 查询用户信息，以便在业务流程中获取用户的基本身份信息。

## 功能名称和一句话概括

网关用户查询 — 业务系统通过 AppId/AppSecret 认证后查询用户信息。

## 补充约束

- 所有请求必须携带 X-Admin-AppId 和 X-Admin-AppSecret 请求头
- 查询结果不包含敏感信息（密码哈希等）

## 关键验收条件摘要

1. [ ] 按用户名/手机号搜索用户，分页返回
2. [ ] 按 ID 批量查询用户
3. [ ] 无效的 AppId/AppSecret 返回 401

## 明确列出"范围外"

- 不提供用户创建/修改能力
- 不提供用户权限信息（由回调机制获取）
