The original analysis proposed a broad browser-authentication direction, including public SPA and
standard logout options that are not part of the accepted first phase. It remains available in Git
history and [superseded PR #127](https://github.com/philfanzhou/SignaCore/pull/127). Do not use it as
an implementation contract.
